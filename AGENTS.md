# AGENTS.md — «Авача»

Правила проекта для Qoder. Файл читается автоматически из корня репозитория.
Источник — `.qoder`; правила разложены по областям задач.

## Проект

- VK Mini App «Авача»: гонка на собачьих упряжках на Камчатке, зрители и участники.
- Фронтенд — корень репозитория: React 18, TypeScript, Vite, VKUI 8, vk-bridge, vk-mini-apps-router, TanStack Query, openapi-fetch, VK Карты (mmr-gl).
- Бэкенд — `backend/`, отдельный git-репозиторий (FastAPI). Правки только в рамках явной backend-задачи.
- Структура: экраны — `src/panels`, общие компоненты — `src/components`, моки — `src/api/mocks`, роутинг — `src/routes.ts`, карта — `src/map/MapView.tsx`.
- API-контракт: `docs/openapi.json` → `src/api/schema.d.ts` (генерация `npm run gen:api`).
- Дизайн-источник: макеты `docs/figma/v2/` и их описание `docs/figma/v2/index.md`.

## Границы задач

- Одна задача — один коммит, сообщение в формате `feat|fix|docs(область): суть`.
- Читай только файлы из задачи и их прямые импорты, не весь проект.
- Не добавляй пакеты без разрешения.
- Не запускай Playwright и скриншоты без прямой просьбы — скрины делает автор.
- Полный `build` и `lint` — только по прямой просьбе. Перед коммитом достаточно `tsc --noEmit` по затронутым файлам.
- В ответе: список изменённых файлов, хеш коммита и одна строка о том, что не удалось.

## Код

- Строгий TypeScript, без `any`. Только функциональные компоненты и хуки.
- Сначала компоненты и токены VKUI; свои стили — только через CSS-переменные `--avacha-*` и токены VKUI.
- Светлая тема по умолчанию, акцент `#045890`. Цвета и размеры не хардкодь.
- Типы API — только из сгенерированной схемы; поля не придумывай, `schema.d.ts` руками не редактируй.
- Все данные — через слой `src/api` на TanStack Query. Моки — только fallback, когда API недоступен.
- Офлайн: показывай последние данные из persisted cache и явно подписывай время обновления.
- Карта — только через интерфейс `MapView`, чтобы движок можно было заменить. Ключ — `VITE_VK_MAPS_KEY`, без ключа работает заглушка.

## Тексты

- Только русский язык. Слово «Берингия» не использовать, только «Авача».
- Время трекера не называть официальным: официальное время — только судейские отметки.
- Не писать «остановился» про участников; положение подписывать временем («Положение на 14:32»).

## Язык

- Технические термины, идентификаторы, имена файлов, комментарии и сообщения коммитов — по-английски: fallback, endpoint, adapter, mock, cache, polling, snap, bottom sheet, offline. Без калек («фолбэк», «ручка», «шторка») в коде.
- Тексты интерфейса для пользователя — на русском.
- Ответы автору — по-русски, термины — английские.

## Бэкенд (`backend/`)

- Python 3.12+, FastAPI, async SQLAlchemy 2, Alembic, PostgreSQL 16, Redis 7, Celery, Poetry, SQLAdmin.
- Стиль: ruff (line-length 100), pytest в asyncio-режиме, Poetry для зависимостей.
- Контракт первичен: после изменения API обнови `openapi.json` (`scripts/export_openapi.py`) и регенерируй `src/api/schema.d.ts`.
- Официальное время — только судейские отметки. SOS-сигнал — только в admin API, никогда в публичном.
