# «Авача» — VK Mini App

Мини-приложение VK для зрителей и участников гонки на собачьих упряжках «Авача» на Камчатке. Проект хакатона Skillbox (октябрь — ноябрь 2026, в процессе).

В приложении: карта трассы с КП и позициями участников, маршрут с профилем высот, результаты, программа по дням и карта зрительских локаций. Последние загруженные данные доступны без сети.

**Команда:** фронтенд — Прохор Ефимов (архитектура, навигация, вёрстка по макетам Figma, моки данных, требования к API), бэкенд — Степан, дизайн — команда дизайнеров.

## Стек

| Слой | Технологии |
|---|---|
| UI | React 18, TypeScript (strict), VKUI 8, `@vkontakte/icons`, шрифт Onest |
| Сборка | Vite 8, ESLint, Prettier |
| VK | vk-bridge, vk-bridge-react, vk-mini-apps-router (hash-роутинг панелей) |
| Данные | TanStack Query 5 + persist в `localStorage`, openapi-fetch |
| Контракт API | `docs/openapi.json` → `src/api/schema.d.ts` (`npm run gen:api`, openapi-typescript) |
| Карта | Yandex Maps JS API 2.1 через адаптер `MapView` → `YandexMapView` (при сбое SDK — PNG-заглушка) |
| Бэкенд (отдельный репо в `backend/`) | FastAPI, async SQLAlchemy 2, Alembic, PostgreSQL 16, Redis 7, Celery, Poetry |

## Приёмы

- **Контракт первичен.** Типы только из сгенерированной схемы; `schema.d.ts` руками не правят. Поля API не выдумывают.
- **Данные через `src/api` + TanStack Query.** Моки — fallback при недоступности API, не основной источник.
- **Офлайн.** Persisted cache: показывают последние данные и подписывают время обновления.
- **Карта за интерфейсом `MapView`.** Сейчас движок — Yandex Maps; панели не импортируют SDK напрямую (`YandexMapView`, `yandexSdk`).
- **Фильтры карты.** Дисциплина — query на сервер (`discipline_ids`); «Мои фавориты» — клиентское пересечение с `favorites/ids` (общий кэш карты не ломают).
- **UI на VKUI.** Свои стили — CSS-переменные `--avacha-*` и токены VKUI; цвета/размеры не хардкодят. Светлая тема, акцент `#045890`.
- **Только функциональные компоненты и хуки**, без `any`.
- **Структура:** экраны — `src/panels`, общие компоненты — `src/components`, моки — `src/api/mocks`, роутинг — `src/routes.ts`.
- **Тексты UI** — на русском («Авача», не «Берингия»). Идентификаторы, комментарии и коммиты — на английском.
- **Коммиты:** `feat|fix|docs(область): суть`, один смысл — один коммит. Push в `origin` — только по явной просьбе.

## Запуск

```bash
npm install
cp .env.example .env
npm run dev
```

Сборка и проверка:

```bash
npm run build
npm run preview
npm run lint
npm run format
```

## Окружение

В разработке `VITE_API_URL` оставляют пустым. Dev-сервер Vite проксирует `/api` (и `/media`) на бэкенд, поэтому браузер ходит на свой origin и не упирается в CORS.

Для сборки с живым API укажите публичный адрес:

```bash
VITE_API_URL=https://example.com
```

### Презентация на моках (ветка `deploy` → GitHub Pages)

Ветка **`deploy`** — только фронт для защиты: данные из фикстур, без бэкенда.

```bash
git checkout deploy
VITE_USE_MOCK=true npm run build
VITE_USE_MOCK=true npm run preview
```

Публикация: push в `deploy` собирает моки и заливает артефакт в ветку `gh-pages`.

В **Settings → Pages → Source**: `Deploy from a branch` → ветка **`gh-pages`** → папка **`/ (root)`** → Save.

Сайт: `https://prohorweb.github.io/vk-app/`.

На карте в меню «⋯» блок **Демо**:
- «До старта» / «Гонка идёт» / «Финиш» — переключают фикстуры;
- «Движение Дорохова» — после «Гонка идёт» двигает маркер по треку (~3 с).

Ключей и секретов в проекте нет. Без ключа карт — PNG-заглушка.

## Экраны

Нижнее меню: Старт, Карта, Участники, Результаты, Ещё.

В «Ещё»: Маршрут, Программа, Новости, Гостям, Профиль.

Карточка участника открывается из списка участников и из шторки на карте. На карте вместо карты стоит заглушка.
