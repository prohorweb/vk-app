# Задание бэкенду: зрительские локации и seed

## Контекст

Фронт зрительских локаций и карты работает на реальных данных, но при проверке нашлись две проблемы в `scripts/seed_mock.py` и `docker-compose.yaml`. Фронт обошёл их частично (поправил координаты в БД SQL-ом и скрыл `category=other`), но при следующем `seed_mock.py --reset` всё вернётся. По договорённости бэкенд не трогали — ниже что нужно починить.

---

## 1. Координаты зрительских локаций в сиде — заглушки

В `scripts/seed_mock.py`, `VIEWER_LOCATIONS`:

```
Главная сцена 53.000 / 158.000
Шатёр         53.001 / 158.001
Фотозона      53.002 / 158.002
Этнозона      53.003 / 158.003
Фудкорт       53.004 / 158.004
Детская зона  53.005 / 158.005
```

Это ровная диагональ в горах западнее Петропавловска-Камчатского (~45 км). В итоге карта уезжает в горы, а 6 из 7 плашек слипаются в одну точку.

**Что сделать:** поставить реальные координаты вокруг б/к им. Фатьянова (просп. Циолковского, 25), разнести на 100–300 м. Для демо в БД были записаны такие (можно взять за основу):

```
Главная сцена 53.0960 / 158.6370
Шатёр         53.0966 / 158.6380
Фотозона      53.0954 / 158.6362
Этнозона      53.0959 / 158.6356
Фудкорт       53.0968 / 158.6364
Детская зона  53.0949 / 158.6378
```

**Приёмка:** на `#/more/program/spectator` плашки разнесены, карта стоит на Петропавловске, а не в горах.

## 2. Сид не читает `data/route-kamchatka.json` в контейнере

В `docker-compose.yaml` у сервиса `api` смонтированы только `app`, `alembic`, `alembic.ini`, `media`. Папок `data/` и `scripts/` нет. Поэтому `python -m scripts.seed_mock` внутри контейнера не видит `data/route-kamchatka.json` и уходит в фоллбэк «прямые линии»:

- `StageRoutePoint` — 20 точек на этап вместо реальных 88/56/77…,
- КП, трек и позиции участников — на прямой линии, мимо трассы (баг «все точки сбились»).

**Что сделать:**

1. Добавить монтирование `data/` (и `scripts/`, если сид запускается из контейнера) в сервисы, которые читают эти файлы:

```yaml
  api:
    volumes:
      - ./app:/app/app
      - ./alembic:/app/alembic
      - ./alembic.ini:/app/alembic.ini
      - ./media:/app/media
      - ./data:/app/data
      - ./scripts:/app/scripts
```

2. Сделать отсутствие `data/route-kamchatka.json` **ошибкой**, а не `WARNING ... Будут сгенерированы прямые линии`. Сейчас тихий фоллбэк маскирует проблему.

**Приёмка:** после `docker compose run --rm api python -m scripts.seed_mock --reset` в логе `StageRoutePoint: 400` (а не 120), трасса этапа 1 — 88 точек, позиции участников идут по трассе.

## 3. Состав зрительских локаций vs макет

В макете «Карта зрительских локаций» 5 зон: **Главная сцена, Фотозона, Фудкорт, Этнозона, Детская зона**. В сиде — 7, лишние:

- **Старт гонки** (`category=other`) — это не зона фестиваля; фронт её уже скрывает, но правильно убрать из `VIEWER_LOCATIONS` (или отдавать отдельным флагом `is_festival_zone`).
- **Шатёр** (`category=stages`) — в макете не встречается. Подтвердить у дизайна: оставляем или убираем.
- У «Старт гонки» описание-заглушка («Зрительская площадка: старт гонки.») — если оставляем, дать нормальный текст.

**Приёмка:** после сида в списке только согласованные зоны; `?category=stages|areas|food|kids` отдаёт ожидаемые.

## 4. (Опционально) поле `glyph` у локации

Фронт сейчас рисует иконку по **названию** локации (Фудкорт — нож, Шатёр — домик, Этнозона — глобус, Фотозона — картинка и т.д.), потому что `kind`/`category` не различают, например, Шатёр и Главную сцену (обе `stages`) или Фотозону и Этнозону (обе `areas`). Это хрупко: переименование ломает иконку.

Надёжнее добавить в `ViewerLocation` поле `glyph` (enum `mic | food | house | image | globe | smile` или строка) и отдавать его в `ViewerLocationPublicResponse`. Фронт тогда берёт глиф из API, а не угадывает по имени.

## Что уже сделано на фронте (чтобы не дублировать)

- Фильтр-«таблетки» по `category` (не по `kind`); `kind` остаётся ролью в гонке.
- Контракт (`docs/openapi.json`, `src/api/schema.d.ts`) перегенерирован под `category` и `/participants/favorites/ids`.
- Иконки плашек — стандартные VKUI по локациям.
- «Старт гонки» (`category=other`) временно скрыт на фронте.
- Координаты в БД поправлены SQL-ом для демо; сид не менялся.

Пункты 1–2 — блокеры для нормальной демо-данных, их стоит сделать в первую очередь.
