# demo seed: актуализировать данные трекера

**Приоритет:** P1
**Endpoint:** `GET /api/v1/map/participants?stage_id=1`

## Сейчас

На stage 1 (проверка 25.10.2026):

- `recorded_at = 2026-10-16` у всех маркеров — 9 дней назад;
- `km_from_start = 100.0` у всех участников;
- `average_speed_kmh = null`;
- все участники `freshness_status: stale`.

## Нужно

- Генерировать сид относительно `now`, а не фиксированной даты.
- Разные `km_from_start` и `average_speed_kmh`, чтобы участники были распределены по трассе.
- Смесь `fresh` / `delayed` / `stale`, чтобы фронт мог проверить все подписи.

## Acceptance criteria

- [ ] Баннер «Положение на …» показывает актуальное время.
- [ ] На карте встречаются разные `freshness_status`.
- [ ] Маркеры распределены по трассе, а не все на финише.

## Контекст

- Фронт: `describePositionsBanner` в `src/panels/MapPanel.tsx`.
- Формулировка на фронте: «Положение на {время}», «данные устарели».
