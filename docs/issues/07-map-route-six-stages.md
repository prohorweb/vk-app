# demo seed: 6 этапов «Авачи» с реальным маршрутом Камчатки

**Приоритет:** P0
**Endpoints:** `GET /api/v1/directory/stages`, `/api/v1/stages/{stage_id}/track`,
`/api/v1/stages/{stage_id}/checkpoints`, `/api/v1/map/participants`
**Статус:** закрыто в backend `develop` (`2d8dc00`, 28.10.2026, PR #62 `fix-07-issue`).
Фронт уже готов и работает на встроенном fallback-маршруте.

## Зачем

Фронт карты перерисован под новый макет: на экране видны **все 6 этапов** — весь
маршрут жёлтым, выбранный этап красным. Сейчас API отдаёт **3 этапа** и треки в
районе **Якутии** (`lng ≈ 128`, `lat ≈ 61–63`), поэтому карта с API уезжает не в
ту точку и не показывает гонку «Авача».

Реальный маршрут (6 этапов, Камчатка) лежит в Google My Maps:
`mid=1WEiJwD5eXRZv5cvMrn0Y7SI4ubcGPG0`.
Экспорт: `https://www.google.com/maps/d/kml?mid=…&forcekml=1`.

## Что сделать в seed

1. `STAGES`: 6 этапов из таблицы, `name = "Этап {number}. {название}"`,
   `order_index = number - 1`, `finish_time = start_time + длительность`.
   `status`: этап 1 — `active` (или `planned`, если гонка ещё не началась — см. п. 5),
   остальные `planned`.
2. `StageRoutePoint`: разложить `coordinates` из JSON по `position` (0..N-1) для
   каждого этапа. Сейчас маршрут — 20 точек по прямой между случайными КП.
3. `Checkpoint`: старт/финиш — из `start`/`finish` этапа, КП-1 и КП-2 — точки
   нитки на 30 % и 70 % пути, чтобы маркеры лежали на трассе. Сохранить
   `km_from_race_start` (накопительно по этапам), `kind`, `order_index`.
4. Базовые координаты генерации треков (`BASE_LAT`, `BASE_LON`) перевести на
   Камчатку: `53.30 / 158.50` (сейчас `62.0 / 129.0` — Якутия), разброс ±0.25.
5. После пере-сида сбросить кэш публичных ответов, иначе API продолжит отдавать
   старую нитку: ключи `public:*` в Redis (`public:map:route:{id}`,
   `public:map:positions:{id}`, …).

## Контракт: что уже потребляет фронт

- `GET /directory/stages` — 6 этапов, `number`, `distance_km`, `start_time`,
  `finish_time`, `status`.
- `GET /stages/{stage_id}/track` — GeoJSON `LineString`, пары **`[lon, lat]`**;
  `404`, если нитки нет. Фронт дополнительно сверяет первую точку с встроенным
  маршрутом: чужой регион (Якутия) он игнорирует.
- `GET /stages/{stage_id}/checkpoints` — `code`, `name`, `type` (`start` /
  `finish` / `checkpoint`), `lon`, `lat`, `km_from_race_start`.
- `GET /map/participants?stage_id=` — позиции на трассе, `freshness_status`,
  `recorded_at`.

**Нужно расширение контракта** (новый макет, иконка «Место ночёвки»):
`CheckpointKind += camp` (`start | finish | checkpoint | camp`). Это правка
`app/enums.py`, OpenAPI (`scripts/export_openapi.py`) и регенерация
`src/api/schema.d.ts` на фронте (`npm run gen:api`). Пока фронт рисует ночёвки
обычными КП, ничего не ломается.

## Acceptance criteria

```bash
curl -s 'http://127.0.0.1:8000/api/v1/directory/stages?season_id=1' | python3 -m json.tool
# 6 этапов, distance_km 34/56/71/38/56/34, timezone-aware start_time

curl -s 'http://127.0.0.1:8000/api/v1/stages/1/track' | head -c 120
# {"type":"LineString","coordinates":[[158.6374,53.0962], … — Камчатка, не 128/61

curl -s 'http://127.0.0.1:8000/api/v1/stages/1/checkpoints'
# Старт (158.6374, 53.0962) … Финиш (158.3917, 53.3491), 4 точки

curl -s 'http://127.0.0.1:8000/api/v1/map/participants?stage_id=1&limit=3'
# position.lat ≈ 53.1, position.lon ≈ 158.6
```

- [x] 6 этапов в справочнике.
- [x] Треки всех 6 этапов в Камчатке, каждый ≥ 2 точек.
- [x] КП лежат на нитке этапа (старт/финиш совпадают с её концами).
- [x] Позиции участников распределены по трассе, а не в Якутии.
- [ ] После пере-сида кэш `public:*` сброшен — в сиде нет инвалидации, чистим руками.

## Проверка (28.10.2026, `2d8dc00`)

Сид прогнан в отдельной БД (`avacha_check`), чтобы не трогать dev-данные:
`Stage 6`, `Checkpoint 24`, `StageRoutePoint 400`.

| Пункт              | Результат                                                                      |
| ------------------ | ------------------------------------------------------------------------------ |
| Этапы              | 6, дистанции 34/56/71/38/56/34, старты из таблицы выше, этап 4 — ночной        |
| Точек в нитках     | 88 / 56 / 77 / 36 / 55 / 88                                                    |
| Статусы этапов     | этап 1 — `active` + `provisional`, остальные `planned` + `draft`               |
| КП                 | по 4 на этап, `start` / `checkpoint` / `checkpoint` / `finish`, лежат на нитке |
| Точки маршрутов    | `lat` 53.096–53.685, `lon` 158.352–158.832 (Камчатка)                          |
| Позиции участников | `lat` 53.096–53.343, `lon` 158.399–158.695 (на трассе этапа 1)                 |

Что расходится с ТЗ и стоит поправить:

- `km_from_race_start = 0` у всех КП: прежний сид считал накопительный километраж
  (`0 / 10 / 23 / 34` на этапе 1), новый — обнуляет. На карте не видно, но поле
  публичного контракта врёт, и на нём может строиться профиль высот.
- Инвалидации кэша `public:*` в сиде нет: после `--reset` API отдаёт старую нитку,
  пока Redis не почистят.
- Этап 6 в JSON — точная копия этапа 1 (та же нитка, то же направление), хотя
  называется «Пиначево — б/к им. Фатьянова». На «Все этапы» они накладываются
  друг на друга.
- `CheckpointKind.CAMP` добавлен (и попал в OpenAPI), но точек ночёвки в сиде нет —
  фронту пока нечего рисовать.
- Сумма дистанций 289 км, в макете нижней шторки — 288 км.

## Альтернатива сиду: импорт файла маршрута

Ветка `feat-stage-route-file-import` влита в `develop` (PR #59): в админке есть импорт
KML/GPX — парсинг, валидация и лимиты размера, предпросмотр, подтверждение, запись
`stage_route_points` и инвалидация кэша `public:map:route:{id}`. Для новой трассы
достаточно загрузить файл из My Maps, сид править не нужно. Сид оставлен как данные
для чистой демо-БД.

Из `feat-guest` (PR #61) дополнительно пришли `StageRoutePointAdmin` (ручная правка
точек маршрута), блоки статичных страниц, гости и фото для сида.

## Заметки

- В исходной My Maps **этап 6 повторяет геометрию этапа 1** (та же нитка) — это
  дефект исходной карты, не сида. Если нужна другая трасса, её надо поправить в
  My Maps и загрузить файлом через админку.
- Код сида в `develop` теперь совпадает с данными этого воркспейса: `--reset` даёт
  6 этапов Камчатки, а не 3 этапа Якутии.
- Фронт: `src/map/data/route.ts` (встроенный маршрут), `src/panels/MapPanel.tsx`
  (`stageTracks`, `isTrackNearRoute`), `src/map/yandexColors.ts`
  (`MAP_TRACK_COLOR` / `ROUTE_INACTIVE_COLOR`).
