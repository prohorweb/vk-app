### Что нужно задать как фирменные переопределения (только наблюдаемые значения)

```css
:root {
  --vkui--color_background_accent_themed: #045890; /* основная синяя кнопка, выбранный SubnavigationButton («Все этапы») */
  --vkui--font_family_base: Onest, sans-serif;     /* шрифт макета Onest; fallback-стек не определён в макете */
  --vkui--font_family_accent: Onest, sans-serif;
  /* собственные (в VKUI нет аналогов): */
  --avacha-brand-dark-blue: #045890;
  --avacha-secondary-blue: #388BC7;
  --avacha-secondary-light-blue: #A0DAF7;  /* бейдж «# N» */
  --avacha-brand-black: #262626;
  --avacha-brand-red: #E7372F;
  --avacha-success: #2A7C35;
}
```
Замечание: макет #045890 для акцента и #2688EB (VK-синий) на экранах 27–47 сосуществуют; если нужен единый акцент, `--vkui--color_background_accent`, `--vkui--color_text_accent`, `--vkui--color_icon_accent_themed` тоже придётся перекрасить — в макете эти роли для #045890 явно не проверялись (в данных только заливки кнопок, рамок и «Brand/Dark blue»).
