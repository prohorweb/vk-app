## Навигация (выведено)
Старт («Начать», согласие опционально) → Карта (таб 1). Таб-бар: Карта · Участники · Результаты · Программа · Ещё. «Ещё» → шторка снизу (затемнение, закрытие по × / тапу на фон): Профиль, О гонке, Маршрут, Гостям, Новости. Маршрут: фильтр (ползунки) → поповер «Этапы на карте» (Все этапы / Этап N) → карта+шторка (3 положения, немодальная); «i» → копирайт/условия; «⋮» → Печать/Поделиться/Сообщить об ошибке/Обратная связь/Линейка. Служебные состояния: нет сети (кэш / пусто), скелетон, восстановление (Snackbar), до старта, после финиша («Итоги гонки» → Результаты, «Фотоотчёт»).

## Что нового / что поменялось vs старый прототип (/workspace/figma/index.md)
- **Таб-бар:** было «Карта · Участники · Рейтинг · Программа · Ещё» → теперь «Карта · Участники · **Результаты** · Программа · Ещё»; иконки 28pt; активная — бренд-синий #045890.
- **«Ещё»:** раньше пункты Профиль/О гонке/Маршрут/Гостям/Новости встречались в экранах программы; теперь формализовано как шторка снизу с затемнением и закрытием по ×/фону. «О гонке» открывается из этого меню (заметка).
- **Старт:** тот же экран (тексты и опечатка «pussh»), добавлено правило: согласие необязательно; оно определяет, включены ли все уведомления по умолчанию.
- **Маршрут:** вместо старых экранов «Map-Stages/Stage1/Filter/Discipline» (с фильтром по участникам и дисциплинам) — отдельный экран «Маршрут» с немодальной шторкой в 3 положениях, профилем высот из KML, схемой этапов (6), КП, участками трассы; фильтр упрощён до «Этапы на карте» + легенда; новые кнопки i/⋮ с меню; наполнение через админку, замена трека во время гонки.
- **Трекинг/служебные состояния (новое):** офлайн с кэшем, без данных, скелетон ≤10 с, автообновление со Snackbar, «до старта» (обратный отсчёт), «завершена»; правила текстов («Положение на 14:32», «Последняя подтверждённая точка», средняя скорость, не «официальное время», SOS только в админке, неактуальность >45 мин).
- **Шапка:** в служебных состояниях — шапка VK Mini Apps (кнопки «… ×») и таб-бар с подписями.
- **Результаты:** отдельных новых экранов результатов в этом экспорте нет; есть только кнопка «Итоги гонки» в состоянии «завершена» и переименование таба.
